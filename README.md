🐙 Octopus

🌊 Plongez dans l'écosystème de la gestion de projets avec Octopus

Bienvenue sur le dépôt GitHub d'Octopus, une solution open-source complète et intuitive conçue pour transformer la manière dont vous gérez vos projets. Fruit d'une réflexion approfondie et d'une conception axée sur l'efficacité, Octopus vise à être votre centre de commande unique, vous offrant une visibilité à 360° sur chaque aspect de vos initiatives, de l'émergence de l'idée à sa concrétisation finale.

Inspiré par la polyvalence et l'intelligence de son homonyme marin, Octopus est bâti pour s'adapter à vos besoins spécifiques. Que vous soyez un développeur indépendant cherchant à organiser vos side-projects, une startup agile nécessitant une vue d'ensemble rapide, ou une équipe plus structurée désirant optimiser sa collaboration, Octopus est l'outil qu'il vous faut pour naviguer avec aisance dans les eaux parfois complexes du développement logiciel et de la gestion de produit.

✨ Fonctionnalités Clés : Une Vision à 360° de Vos Projets

Octopus est conçu pour vous offrir une maîtrise totale, avec des fonctionnalités pensées pour simplifier votre quotidien de développeur et de chef de projet :

    📊 Tableaux de bord intuitifs : Visualisez l'avancement de vos projets en un clin d'œil grâce à des interfaces claires et personnalisables. Suivez les métriques essentielles et identifiez rapidement les points d'attention.

    📝 Gestion des Tâches Avancée : Créez, attribuez, priorisez et suivez vos tâches avec une flexibilité maximale. De la simple todo à la gestion de sprints complexes, Octopus s'adapte à votre méthodologie.

    💬 Collaboration en Temps Réel : Facilitez la communication et le travail d'équipe. Partagez des informations, commentez des tâches et assurez une synergie parfaite entre les membres de votre équipe.

    📈 Suivi des Performances et Rapports : Analysez les métriques clés pour optimiser vos processus et prendre des décisions éclairées. Comprenez où se situe votre projet et comment améliorer l'efficacité.

    🎬 Gestion Administrative Complète : Prenez le contrôle total de votre plateforme.

        Contrôle des Utilisateurs : Gérez les accès et les rôles de chaque membre.

        Gestion des Vidéos : Intégrez et organisez vos ressources vidéo directement dans vos projets.

        Gestion des Citations : Suivez et référencez les citations importantes liées à vos projets ou à votre domaine.

🛠️ Stack Technologique : Robuste et Moderne

Octopus est construit sur des technologies éprouvées et performantes, assurant une base solide et une expérience utilisateur fluide :

    Backend :

        Laravel : Le framework PHP robuste pour une API puissante et scalable.

        Telescope : Un assistant de débogage élégant pour Laravel, garantissant une maintenance aisée.

        Breeze : Pour une authentification rapide et sécurisée.

    Frontend :

        React : La bibliothèque JavaScript pour une interface utilisateur dynamique et réactive.

        Inertia.js : Le pont magique entre Laravel et React, offrant une expérience SPA sans la complexité des API.

        Node.js : L'environnement d'exécution JavaScript essentiel pour le développement frontend.

    Outils de Développement & Déploiement :

        Docker : Pour un environnement de développement cohérent et portable.

        PNPM : Un gestionnaire de paquets rapide et efficace pour vos dépendances JavaScript.

🚀 Démarrage Rapide

Pour plonger directement dans Octopus et commencer à gérer vos projets, suivez ces étapes simples :

Prérequis

Assurez-vous d'avoir les éléments suivants installés sur votre machine :

    Docker

    Node.js (avec PNPM inclus ou installé séparément : npm install -g pnpm)

Installation

Bash

# Clonez le dépôt
git clone https://github.com/fireye992/octoreact.git

# Accédez au répertoire du projet
cd octoreact

# Installez les dépendances backend (Laravel)
composer install

# Installez les dépendances frontend (React avec PNPM)
pnpm install

# Configurez votre environnement
# Copiez le fichier d'exemple des variables d'environnement
cp .env.example .env
# Ouvrez le fichier .env et remplissez les variables nécessaires (base de données, etc.)
# Générez la clé d'application Laravel
php artisan key:generate

# Lancez les migrations de la base de données
php artisan migrate

# Lancez l'application en mode développement (serveur Laravel et serveur de développement Vite)
pnpm run dev

Votre application devrait maintenant être accessible dans votre navigateur à l'adresse indiquée par Vite (généralement http://localhost:5173/).
